# Vitalbet - Online Betting Platform

Vitalbet is a modern online betting platform built with cutting-edge web technologies.

## Features
- User authentication and account management
- Sports betting and live odds
- Secure payment processing
- Real-time bet tracking
- Admin dashboard
- Responsive mobile design

## Tech Stack
- Frontend: React.js, TypeScript, Tailwind CSS
- Backend: Node.js, Express.js, PostgreSQL
- Authentication: JWT
- Payment: Stripe Integration

## Getting Started

### Prerequisites
- Node.js 18+
- PostgreSQL 12+
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/emmanuelkkipkirui-pixel/Vitalbet.git
cd Vitalbet

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local

# Run the application
npm run dev
```
